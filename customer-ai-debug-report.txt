2. ARCHITECTURE (as prepared)
================================================================================
Vercel (client/, SPA, vercel.json rewrite) -> VITE_API_URL=https://<render>/api
  -> Render Docker web service (one container):
     deploy/blitz/entrypoint.sh -> deploy/blitz/supervisor.mjs
       1. prepare /app/data paths + idempotent Hermes first-boot seeding
       2. start Node backend (HOST=0.0.0.0, $PORT from Render)
       3. wait /api/health == 200 (needs MongoDB reachable, else exit 1)
       4. start Hermes gateway (spawns WhatsApp Baileys bridge)
  -> MongoDB Atlas + Redis Cloud (external, never in the container)
Same container is required because human-queue sends invoke local `hermes send`.
Hermes remains the only WhatsApp transport owner; /api/whatsapp/* are 409.
