B — FILES CHANGED (this round)
  server/src/server.js
      + binds HOST (env, default 127.0.0.1) — Node never exposed on a public
        port; Nginx terminates TLS to 127.0.0.1:5000 (HOST=0.0.0.0 only if a
        container needs it).
      + CORS allowlist from CLIENT_ORIGIN as a comma-separated list, e.g.
        'https://customer-ai.vercel.app,http://localhost:5173'. Disallowed
        origins are NOT reflected (no ACAO -> browser blocks). Requests with
        no Origin (Hermes webhooks, curl) still pass.
      + app.set('trust proxy', 1) so the /api 240/min rate limit keys on the
        REAL client IP behind Nginx (otherwise all users share the proxy's IP
        and the aggregate limit misfires). Safe here because the backend
        binds 127.0.0.1 and only Nginx can reach it.

  server/src/services/whatsapp.service.js
      HERMES_HOME          (env) defaults to ~/.hermes        (already existed)
      HERMES_GATEWAY_STATE (env) defaults to HERMES_HOME/gateway_state.json
                            (already existed)
      + HERMES_STATE_STALE_MS default 300000 (5 min) — an age SUSPICION only.
      + PID-liveness fallback (replaces the earlier age-only rule): the
        gateway only rewrites gateway_state.json on lifecycle transitions and
        agent turn boundaries (the 30s heartbeat lives in the separate
        state/gateway.heartbeat file), so an idle but healthy gateway's state
        file legitimately ages. Age alone therefore caused false "stopped
        reporting" alarms. Stale is now true only when:
            updated_at older than STATE_STALE_MS
            AND the recorded gateway PID is NOT alive
            (or its /proc/<pid>/stat field-22 start-time fingerprint does not
             match the recorded start_time — PID-reuse guard, the same model
             Hermes itself uses).
      + stale gateway -> DISCONNECTED with
        ("The Hermes gateway stopped reporting status; check that it is running.").
      + unreadable/missing file -> DISCONNECTED + generic
        "WhatsApp status is unavailable right now." — never leaks filesystem
        paths to the browser.
      + exposes a "stale" boolean in the status payload.
